How to play

  1. Pick a room. Jump into a random room, or create a private one and send the invite link to your friends.
  2. Set the game. In a private room the host chooses the number of rounds, time per question, hints, difficulty and category.
  3. Answer fast. Everyone sees the same question. Correct answers earn more points the quicker you are, with a bonus for streaks.
  4. Watch for hints. As the timer runs down, wrong choices disappear one by one. Waiting makes it easier but earns fewer points.
